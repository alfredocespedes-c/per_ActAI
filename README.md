# ActaAI MVP v0.1.0

MVP para cargar audio, separar hablantes, revisar transcripción, resumen ejecutivo, acuerdos y participantes.

## Estructura

- `frontend/`: React + Vite
- `backend/`: FastAPI preparado para integrar transcripción y diarización real
- `.github/workflows/deploy-pages.yml`: despliegue del frontend a GitHub Pages

## GitHub Pages

El frontend se publica desde `main` mediante GitHub Actions.
